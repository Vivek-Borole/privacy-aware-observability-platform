# v0.1.0 local release verification

**Scope:** local-only, synthetic telemetry. No customer data, production
credentials, or cloud service was used.

## Measured benchmark

The benchmark was run on 2026-08-20 using `bash scripts/run-benchmark.sh` on
an Apple M3 Pro Mac with 18 GB memory. Colima provided Docker with six CPUs and
eight GiB memory. The raw JSON and environment capture are intentionally
ignored; they were manually reviewed before publishing this summary.

| Gate | Measured result | Result |
| --- | ---: | --- |
| Ingestion duration | 600.134 seconds | complete |
| Synthetic spans accepted | 3,060,000 | pass |
| Ingestion failures | 0 | pass |
| Sustained ingestion | 5,098.858 spans/second | pass (minimum 5,000) |
| Sanitized trace lookup p95 | 33.703 ms across 100 sampled traces | pass (maximum 3,000 ms) |

The recorded ingestion latency percentiles were p50 407.684 ms, p95 952.306
ms, and p99 1,508.980 ms. The lookup latency percentiles were p50 15.817 ms,
p95 33.703 ms, and p99 66.509 ms. These are local benchmark observations, not
a claim of hosted production capacity.

## Reliability and privacy checks

The following completed against the local Compose stack on 2026-08-21:

- `PAOP_SKIP_BUILD=1 bash scripts/integration-smoke.sh` — authenticated
  OTLP ingest, tenant isolation, redaction, durable persistence, deletion
  request behavior, derived metrics, and a payload-silent Redpanda audit.
- `PAOP_SKIP_BUILD=1 bash scripts/recovery-smoke.sh` — a uniquely named
  synthetic tenant and trace survived tailer, broker, delayed-storage, and
  persistence-worker restarts. A duplicate delivery produced exactly one
  committed query event; seeded secret and fabricated email markers were
  absent from queried data and service logs.
- `PAOP_SKIP_BUILD=1 bash scripts/backpressure-smoke.sh` — a uniquely named
  synthetic tenant retained 1,000 active traces and recorded one explicit
  `evicted_pressure` decision.
- `go test ./...`, `pnpm console:typecheck`, `pnpm console:build`,
  `pnpm audit --audit-level high`, and `bash scripts/secret-scan.sh` passed
  during the release verification cycle.

The recovery and backpressure scripts use a run-specific tenant, trace, and
test key so a prior local run cannot make a later run appear to pass or fail.
